# おもちゃ救助隊 — ふたりで、ただいま。

同じパソコンで遊ぶ、キーボードの小さなロボットとマウスの磁力ドローンの協力ゲームです。

**[ゲームを開く](https://metaborin.github.io/toy-rescue-web/)**

読み込み後、タイトルの「はじめる」を押します。「あそびかた」でふたりの担当と操作を確認できます。説明は「タイトルへ もどる」またはEscで閉じられます。導入が終わったら、ゲーム画面をクリックしてマウス操作を始めます。

| 担当・操作 | できること |
|---|---|
| ロボット：WASD / 矢印 | 移動 |
| ロボット：E | 電源・ハンドル・ひも・係留 |
| ドローン：マウス＋左ドラッグ | 定規や歯車、おもちゃを運ぶ。船の輪を引く |
| Esc | ひとやすみ・マウス解除・全画面から戻る |
| Rを長押し | 最初からやりなおす |
| 画面上のボタン | 画質・音・全画面・ひとやすみ |

再開はゲーム画面をクリックし、キーとマウスを一度はなしてください。別のタブに移るとポーズになり、持っていた物が戻ります。

ほんの丘、つみきの工房、紙の森、ゆらゆら港の4つの島で、くま・うさぎ・ことりを助けます。つりあいリフトのスターは任意です。港ではロボットが船に乗り、ドローンが輪を右岸へドラッグ。到着したらEで係留します。最後は3匹が基地へ集まり、役割を交代してもう一度遊べます。

画質は「かるい」で始まります。「くっきり」に切り替えると3Dの輪郭や影が細かくなります。どちらも文字の解像度は同じです。選んだ画質はこのブラウザーに保存されます。

WebGL2とWebAssemblyに対応したデスクトップブラウザー、キーボードとマウスが必要です。Chromebook実機での性能・互換性、および子ども2人での試遊評価は未確認です。スマートフォン向けのタッチ操作はありません。

このリポジトリにはWeb配布物だけを含みます。Unityの開発プロジェクト、Windows版、個人の作業記録は含みません。

## アプリ追加とオフライン保存（PWA）

- HTTPSの公開URLを対応ブラウザで開き、「アプリ・オフライン」→「オフライン用に保存」で全ファイルの確認が終わるまで待ってください。初回の準備には通信が必要です。
- 準備完了後は、同じ端末・ブラウザから通信なしでゲームを開けます。「アプリを追加」またはブラウザのインストールメニューで独立したウィンドウに追加できます。追加とオフライン保存は別の操作です。
- 保存中は進捗を表示し、中断できます。通信失敗・容量不足・不完全な更新では、新しい一式を使わず、保存済みの版とセーブを残します。
- 更新を準備しても、ゲーム中に再読み込みしません。ゲームを終え、このアプリのタブ・ウィンドウをすべて閉じてから開き直してください。
- キャッシュはこのアプリのURL範囲と名前で分離しています。他のアプリのキャッシュ、localStorage、IndexedDBを削除しません。
- ブラウザが保存を削除した場合は、通信できる場所で再び準備してください。サイトデータの手動削除はゲームの記録も消します。OSへの実際のインストール、Chromebook・スマートフォン実機は別途確認が必要です。

PCのキーボードとマウスが必要です。保存対象はUnity本体を含む約16.6 MBです。既存の画質設定を維持します。元からステージ進行は終了後に永続保存しない仕様で、PWA化でもこのゲーム仕様は変えていません。Windows向けUnity原本は変更しません。
